# Hola! 西班牙語學院

以台灣國中英文程度為起點的互動式西班牙語學習網站，採用深色模式與英文輔助理解。

## 使用方式
1. 解壓縮整個 ZIP，請勿只移動單一 HTML。
2. 開啟 `index.html`，或把整個資料夾內容上傳到 GitHub repository。
3. GitHub Pages 設定為 Deploy from a branch，選擇 `main` 與 `/ (root)`。

## 專案結構
- `index.html`：首頁與等級入口
- `style.css`：共用深色主題、響應式版面、背誦清單樣式
- `script.js`：詞彙打勾、題庫流程、進度與錯題儲存
- `course-data.js`：各單元詞彙與練習題資料
- `A1/`：入門首頁與六個獨立單元 HTML
- `A2/`：初級首頁與三個獨立單元 HTML
- `B1/`：中級首頁與三個獨立單元 HTML
- `review.html`：錯題複習

## 學習功能
- 12 個獨立單元，每單元有完整詞彙清單、繁體中文意思與英文對照
- 每個詞彙都能勾選「已背熟」，進度會儲存在瀏覽器 `localStorage`
- 每個單元有 10 題以上互動題庫，答題後會顯示正確答案與解釋
- 錯題會自動記錄在複習頁，完成進度與連續學習天數也會儲存
- 預設深色模式，不需要 API Key 或外部套件

> 發音目前以文字提示為主，尚未加入真人音訊。西語部分發音會因地區而異，課程中有標示常見差異。
